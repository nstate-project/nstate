## Key data sources

| Domain | Institution | Dataset | URL |
|---|---|---|---|
| National statistics | ISTAT | Conti delle Amministrazioni Pubbliche | https://www.istat.it/en/government-finance |
| Tax receipts | MEF / Agenzia delle Entrate | Entrate tributarie | https://www.finanze.gov.it/en/fiscal-system/statistics/ |
| Public spending | RGS | Rendiconto generale dello Stato | https://www.rgs.mef.gov.it/VERSIONE-I/e_government/amministrazioni_pubbliche/ |
| Public debt | Banca d'Italia | Debito delle Amministrazioni Pubbliche | https://www.bancaditalia.it/statistiche/tematiche/finanza-pubblica/ |
| Open spending | OpenCUP / OpenBDAP | Banca Dati Amministrazioni Pubbliche | https://openbdap.rgs.mef.gov.it/ |

## First-wave priorities

1. **Debito pubblico** — public debt at ~135% GDP, highest in G7 after Japan
2. **Spesa pubblica per funzione** — COFOG breakdown comparing Italy to EU27
3. **Dipendenti pubblici** — public sector headcount and pay relative to private sector
4. **Evasione fiscale** — Italy's tax gap estimated at €80-100bn/year (Agenzia delle Entrate data)

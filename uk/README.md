## Key UK data sources

| Domain | Institution | Primary dataset |
|---|---|---|
| Public spending | HM Treasury | PESA, Whole of Government Accounts |
| Tax receipts | HMRC | Tax and NIC receipts statistics |
| GDP / productivity | ONS | National Accounts, Productivity |
| Public sector employment | ONS + Cabinet Office | Public Sector Employment, Civil Service Statistics |
| Welfare | DWP | Stat-Xplore benefit caseloads |
| Education | DfE | School Census, Funding Statistics |
| Energy | Ofgem + DESNZ | Price Cap data, Energy Statistics |
| Health | NHS England | Reference costs, workforce statistics |
| Procurement | Cabinet Office | Contracts Finder, Find a Tender |
| Major projects | IPA | Annual Report on Major Projects |
| Policy evaluation | NAO | Value for money reports |
| Forecasts | OBR | Economic and Fiscal Outlook, Welfare Trends |

All sources are free and publicly available. No FOI required for core data.
